# Dataset access and redistribution

The manuscript uses the PolSAR vehicle dataset of Wang et al., Scenario 1 (2,120 chips, ten classes, acquisition angles 25°, 30°, 45°).

- Original PolSAR image chips and MATLAB files are **not** included.
- Researchers must obtain access from the original provider under its terms.
- These terms have **not yet been independently verified here**; do not assume publication rights for data-derived patches, embedded arrays, checkpoints or sample screenshots.
- Source code, configurations, split indices and output metrics should be separately reviewed for credentials, private paths and possible redistribution restrictions.

This repository is private until the dataset policy, implementation, evidence and license have been audited.
