# Pre-publication reproducibility audit checklist

- [ ] Confirm dataset source URL, citation and actual redistribution/reuse terms.
- [ ] Audit notebooks for tokens, secrets, mount points, personal paths, and embedded datasets.
- [ ] Reconcile every manuscript table/figure number against raw seed-wise outputs.
- [ ] Identify paired vs cross-series experiments and preserve exact per-run provenance.
- [ ] Archive model/config hashes, split indices and environment details, as permitted.
- [ ] Validate QPU job IDs, counts, shots, calibration metadata and checkpoint references.
- [ ] Check code runs from a fresh environment and document exact reproduction commands.
- [ ] Make the GitHub repository public only after verified materials and license are finalized.
- [ ] Add verified public repository URL in the IEEE Access Data and Implementation Availability statement.
